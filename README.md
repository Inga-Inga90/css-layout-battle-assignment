Responsive Layout – CSS Grid
Project Description

A responsive website layout built using HTML and CSS Grid. The design adapts to desktop, tablet, and mobile screen sizes.

Technologies Used
HTML5
CSS3
CSS Grid
Media Queries
Features
Responsive desktop layout (1440px)
Responsive tablet layout (768px)
Responsive mobile layout (375px)
Header with navigation
Sidebar navigation
Main content section
Responsive footer
Hamburger menu icon on smaller screens
Layout Structure
Desktop
Header height: 80px
Sidebar width: 280px
Main content width: 1160px
Tablet
Container width: 768px
Sidebar width: 200px
Main content width: 568px
Navigation links are hidden
Mobile
Container width: 375px
Main content takes full width
Sidebar moves below main content
Footer elements are stacked vertically
Responsive Breakpoints
Tablet: max-width 1024px
Mobile: max-width 768px
Project Files
index.html – HTML structure
style.css – Styling and responsive layout
